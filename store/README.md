# 스토어 자산

App Store와 Play Store 심사에 넣는 것들. 스크린샷은 **실제 앱을 구동해서** 뽑는다 —
목업은 두 스토어 모두 거절 사유다.

```bash
npx http-server app -p 8787 &
npm i playwright                       # 앱의 의존성이 아니라 이 스크립트의 의존성
node tools/screenshots.mjs store
```

| 폴더 | 규격 | 어디에 |
|---|---|---|
| `ios-6.7/` | 1290×2796 | App Store Connect, 6.7인치 (필수 규격) |
| `android-phone/` | 1080×1920 | Play Console, 휴대전화 스크린샷 |

여섯 장은 앱의 실제 흐름 순서다: 첫 실행 직무 선택 → 카드 앞면 → 정답 → 완료 →
홈 → 카톡 미리보기.

## 아직 없는 것

- **앱 아이콘 고해상도** — `app/icons/icon-512.png`가 있지만 App Store는 1024×1024를
  따로 요구한다
- **Play 피처 그래픽** 1024×500
- **개인정보 처리방침 URL** — 문안은 `docs/privacy.md`에 있고, 공개 URL이 필요하다.
  GitHub Pages를 켜면 `/privacy.html`로 나간다

## 심사에서 물어볼 것

- **마이크·음성 인식 권한** — 왜 필요한지 iOS는 `Info.plist`의 두 문장으로,
  Android는 권한 요청 시점의 화면으로 답한다. 둘 다 "말한 영어를 카드의 정답과
  비교"라는 같은 이유다
- **카카오톡 대화 파일** — 앱은 사용자가 직접 고른 `.txt`만 읽고, 기기 안에서
  파싱한다. 업로드되는 것은 그날 연습할 문장과 앞뒤 맥락뿐이며 번역에만 쓰인다.
  대화 로그 전체는 어디에도 전송되지 않는다
- **계정** — 없다. 로그인도 회원가입도 없고 진도는 기기에만 남는다
