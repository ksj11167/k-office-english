## 심사에서 물어볼 만한 것

**«사용자 생성 콘텐츠»에 해당하나** — 다른 사용자에게 공유되는 콘텐츠가 아니므로
신고·차단 기능 요구사항에 해당하지 않는다. 대화는 본인 기기에만 있고 공유 기능이
없다는 점을 밝히면 된다.

**카카오톡과의 관계** — 이 앱은 카카오와 무관하며, 카카오톡이 사용자에게 제공하는
공식 «대화 내용 내보내기» 파일을 사용자가 직접 불러오는 방식이다. 카카오 API를
쓰지 않고, 카카오톡 데이터에 접근하지 않는다. 앱 이름과 아이콘에 카카오 상표를
쓰지 않았다.

**마이크 권한 사유** — 말하기 연습 채점. 문구는 이미 들어가 있다:
iOS는 `Info.plist`의 `NSMicrophoneUsageDescription`·`NSSpeechRecognitionUsageDescription`,
Android는 매니페스트의 `RECORD_AUDIO`.
