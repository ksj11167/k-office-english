# 번역 서버

## 이게 왜 필요한가

앱이 카톡 대화를 영어로 옮기려면 **Claude에게 요청을 보내야** 합니다. 그 요청에는
«API 키»가 따라붙어야 하는데, API 키는 **결제 수단에 가깝습니다.** 키를 가진 사람은
누구나 그 계정으로 돈을 씁니다.

문제는 앱이 사용자 폰에서 돈다는 겁니다. 앱 안에 키를 넣어두면 **설치한 사람 누구나
꺼낼 수 있습니다.** 웹앱이면 브라우저에서 바로 보이고, 안드로이드 앱이어도 조금만
뜯으면 나옵니다. 숨길 방법이 없습니다.

그래서 이렇게 합니다:

```
   폰의 앱                번역 서버                   Claude
   "이 대화 영어로"  →   (키를 여기 보관)      →   번역 결과
                        요청에 키를 붙여 전달
```

**키는 서버에만 있고, 앱은 키를 모릅니다.** 앱은 "이거 번역해줘"만 말하고, 키를
붙이는 일은 서버가 합니다.

> 회사 법인카드와 같습니다. 직원 전원에게 카드를 복사해 나눠주는 대신, 결제는
> 총무팀이 대신 해줍니다. 직원은 "이거 결제해주세요"만 하면 되고, 카드 번호는
> 총무팀 밖으로 나가지 않습니다.

서버가 하는 일은 그것뿐입니다. 대화를 저장하지도, 계정을 만들지도 않습니다.

## 지금 없으면 어떻게 되나

**앱이 샘플 대화밖에 못 씁니다.** 본인 카톡을 넣으면 "번역할 방법이 없습니다"에서
멈춥니다. 그래서 테스터 12명에게 2주간 써보게 하려면 이게 먼저 있어야 합니다.

## 비용

세션(하루치 대화) 하나에 **약 $0.02**. 한 사람이 하루에 최대 20번까지만 쓸 수 있게
막아뒀으니 1인당 하루 상한은 **$0.4**입니다. 테스터 12명이 매일 한 번씩 쓰면
**한 달에 $7~10** 정도입니다.

Cloudflare 자체는 이 규모에서 **무료**입니다. 나가는 돈은 Anthropic 사용료뿐입니다.

## 설치 — 터미널 없이, 웹 화면에서만

전부 클릭입니다. 프로그램을 깔 필요도, 명령어를 칠 필요도 없습니다.

### 1. Anthropic API 키 만들기

1. [console.anthropic.com](https://console.anthropic.com) 가입
2. **Billing**에서 결제 수단 등록하고 소액 충전 (테스터 규모면 $20이면 한참 갑니다)
3. **API Keys → Create Key** → 나온 키를 복사 (`sk-ant-...`로 시작)

> 이 키는 **한 번만 보여줍니다.** 창을 닫기 전에 복사하세요.

### 2. Cloudflare 계정과 값 두 개

1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입 (무료)
2. **계정 ID**: 대시보드 왼쪽 메뉴 **Workers & Pages**에 들어가면 오른쪽에
   «Account ID»가 있습니다. 복사
3. **API 토큰**: 오른쪽 위 프로필 → **My Profile → API Tokens → Create Token**
   → «Edit Cloudflare Workers» 템플릿 선택 → 만들고 복사
4. **저장 공간 만들기**: **Workers & Pages → KV → Create a namespace**,
   이름은 `QUOTA`. 만들어지면 옆에 뜨는 **ID**를 복사

> KV는 «누가 오늘 몇 번 썼는지»만 세는 작은 저장소입니다. 대화는 여기 저장되지
> 않습니다.

### 3. GitHub에 값 넣기

저장소 → **Settings → Secrets and variables → Actions**

**Secrets** 탭에서 **New repository secret**을 눌러 네 개:

| 이름 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | 1번에서 복사한 키 |
| `CLOUDFLARE_API_TOKEN` | 2-3번 토큰 |
| `CLOUDFLARE_ACCOUNT_ID` | 2-2번 계정 ID |
| `QUOTA_SALT` | 아무 길고 무작위한 문자열. 비밀번호 생성기로 40자쯤 |

**Variables** 탭에서 **New repository variable** 한 개:

| 이름 | 값 |
|---|---|
| `CLOUDFLARE_KV_ID` | 2-4번 KV의 ID |

> Secrets는 한 번 저장하면 **아무도 다시 볼 수 없습니다** — 저도, GitHub 화면에서도.
> 값이 틀리면 고쳐 넣는 게 아니라 새로 덮어씁니다.

### 4. 배포

저장소 → **Actions → Deploy translation proxy → Run workflow**

값이 하나라도 비어 있으면 **무엇이 비었는지 알려주고 멈춥니다.** 성공하면 로그에
워커 주소가 나옵니다 — `https://koe-translate.무언가.workers.dev` 형태입니다.

### 5. 앱에게 서버 주소 알려주기

**Settings → Secrets and variables → Actions → Variables**에 하나 더:

| 이름 | 값 |
|---|---|
| `PROXY_URL` | 4번에서 나온 워커 주소 |

그리고 **Actions → Deploy app to GitHub Pages → Run workflow**.

이제 앱이 그 서버로 번역합니다. **코드는 한 줄도 건드리지 않았습니다** — 배포할 때
이 값을 끼워 넣도록 돼 있습니다. 값을 비우면 서버 없던 상태로 돌아갑니다.

## 잘 됐는지 확인

앱을 열었을 때 홈 화면의 **주황색 «번역 서버가 붙어 있지 않습니다» 안내가 사라지고**,
«내 카톡 대화 가져오기» 버튼에서 «(API 키 필요)»가 빠져 있으면 된 것입니다.

## 남의 대화가 지나가는 코드라서

로직은 작지만 책임이 따라옵니다. 지키기로 한 것과, 그걸 실제로 검사하는 테스트:

| 약속 | 어떻게 지키나 |
|---|---|
| 대화를 기록하지 않는다 | 프롬프트도 응답도 로그에 남기지 않는다. 에러일 때도 |
| 누가 썼는지 모으지 않는다 | IP가 아니라 **소금 친 해시**를 센다. 48시간 뒤 만료 |
| 에러 본문을 흘리지 않는다 | Anthropic의 400 응답은 프롬프트를 되돌려줄 수 있다. 코드로 바꿔 내보낸다 |
| 남의 사이트가 이 키를 못 쓴다 | 허용된 주소 밖 요청은 모델 호출 **전에** 막힌다 |
| 한 명이 예산을 다 못 태운다 | 할당량을 모델 호출 **전에** 차감한다 |

마지막 두 줄의 **"전에"**가 핵심입니다. 호출한 뒤에 막으면 돈은 이미 나간 것입니다.
`worker.test.mjs`가 이 순서를 실제로 검증합니다.

```bash
node server/worker.test.mjs     # 12개, 네트워크도 키도 돈도 들지 않음
```

## 설정 바꾸기

`wrangler.toml`에서:

- `DAILY_LIMIT` — 1인 1일 번역 횟수 (기본 20)
- `MODEL` — 기본 `claude-opus-5`. `claude-sonnet-5`나 `claude-haiku-4-5`로
  내리면 싸지지만 **번역 품질이 이 앱의 전부**이므로 내리기 전에 직접 비교해보길
  권합니다
- `ALLOWED_ORIGINS` — 앱이 서비스되는 주소. 여기 없는 곳에서 온 요청은 거부됩니다

고치고 `main`에 올리면 자동으로 다시 배포됩니다.
