## 1. 기기에만 남는 것

학습 카드와 진도(어떤 카드를 언제 다시 볼지)는 **이용자 기기의 브라우저 저장소**에만
저장됩니다. 저희 서버로 전송되지 않고, 다른 기기와 동기화되지 않습니다. 앱을
삭제하거나 설정 화면의 **"카드와 진도 모두 지우기"**를 누르면 함께 사라집니다.

## 2. 카카오톡 대화 파일

이용자가 직접 고른 대화 내보내기 `.txt` 파일은 **기기 안에서 읽고 분석합니다.**
파일 자체는 어디에도 업로드되지 않습니다.

번역 기능을 쓸 때만, **그날 연습할 문장과 그 앞뒤 맥락 몇 줄**이 번역을 위해
전송됩니다. 전송되는 곳은 이용자가 선택한 번역 제공자입니다:

| 앱을 어디서 쓰는가 | 문장이 가는 곳 |
|---|---|
| Claude 아티팩트 | 이용자 본인의 Claude 세션 (Anthropic) |
| 웹 / 앱, 본인 API 키 입력 | `api.anthropic.com` (Anthropic) |
| 번역 미설정 | 전송 없음 — 번역 기능이 동작하지 않습니다 |

대화 전체 로그, 대화방 이름, 참여자 이름, 날짜는 **전송되지 않습니다.**

API 키를 입력한 경우 그 키는 **이용자 브라우저에만** 저장되며 `api.anthropic.com`
외의 어디로도 전송되지 않습니다. 공용 기기에서는 사용하지 마세요.

## 3. 마이크와 음성 인식

말하기 연습에서 마이크 버튼을 누른 동안에만 음성을 받습니다. 녹음 파일은 저장하지
않으며, 인식된 텍스트는 카드의 정답과 비교한 뒤 화면을 벗어나면 사라집니다.

처리 위치는 실행 환경에 따라 다릅니다:

- **iOS / Android 앱** — 기기 안에서 처리됩니다 (온디바이스 음성 인식). 음성이
  기기를 벗어나지 않습니다
- **웹 브라우저** — 브라우저의 음성 인식 기능을 사용합니다. **Chrome은 오디오를
  Google 서버로 전송합니다.** 이것이 마음에 걸리면 앱 버전을 쓰시거나, 마이크 대신
  정답 보기로 스스로 채점하시면 됩니다
