# K-직장인 영어 — PRD

v1 출시 범위를 자르기 위한 문서. 무엇을 만드는지보다 **무엇을 안 만드는지**가
핵심이다. 설계 근거는 `decisions.md`(D1~D17)에 있고, 여기서는 반복하지 않는다.

- 작성 시점: 프로토타입 동작 확인 후 (`app/` 배포 가능 상태)
- 상태: **v1 범위 재확정** (2026-09-16). 앱이 하는 일은 두 가지 — 전체 번역, 카드
- 출시 일정 제약 없음

---

## 1. 누구를 위한 앱인가

**한국에서 일하는 직장인 중, 영어로 일해야 하는 순간이 가끔 오는 사람.**

- 토익 점수는 있는데 막상 슬랙/미팅에서 한 줄이 안 나오는 사람
- 유학·어학연수 경험이 없고, 학원 다닐 시간도 없는 사람
- "확인하고 말씀드릴게요"를 영어로 어떻게 하는지 매번 검색하는 사람

**대상이 아닌 사람**: 영어 초보(기초 문법이 필요한 사람), 시험 준비생,
영어가 모국어에 가까운 사람.

## 2. 왜 기존 앱으로는 안 되나

| | 문제 |
|---|---|
| 듀오링고 | 게임은 재밌는데 "사과 먹는다"를 배운다. 회사에서 쓸 일이 없다 |
| 스픽 | 말하기 중심은 맞는데 교재가 일반 회화다. 내 상황이 아니다 |
| 번역기 | 그때그때 해결되지만 **남지 않는다**. 같은 문장을 매번 다시 찾는다 |

빈 곳: **한국 직장인이 실제로 쓰는 한국어 표현 → 그 상황의 자연스러운 영어**,
그리고 그게 **입에서 나올 때까지** 반복.

## 3. 핵심 가설

> 사람은 "상황"에 막혀서 말을 못 한다. 직무가 아니라.
> 그런데 같은 상황이라도 **쓰는 단어는 직무마다 다르다.**

측정으로 확인함 (`app/js/job-decks.js` 첫 60장 기준):

- 세밀한 상황 태그 57종 중 직무 간 겹침은 3종뿐
- 굵게 묶으면(보고·일정·요청·거절) 상위 4묶음이 **5개 직무 전부**에 걸침

→ **상황은 세로축, 표현은 가로축.** 둘 중 하나로 통합되지 않는다.
→ 이 측정은 **직무 덱 마일스톤**의 근거로 남는다. v1은 직무로 진입하지 않는다 (D20).

## 4. v1 범위

앱이 하는 일은 **두 가지**다 (2026-09-16 확정).

1. 카톡 내보내기 텍스트를 **그 날 대화 전체** 영어로 옮긴다
2. 그 중 **내가 한 말**을 골라 카드로 연습한다

### 흐름

```
파싱 → 미리보기 승인 → 날짜 분할 → 그 날 전체 번역 → 나 고르기 → 카드
```

「나 고르기」가 번역 뒤로 간 이유는 D19에 있다. 미리보기 게이트는 남는다 —
비용 근거는 사라졌지만 파싱 오류를 잡는 근거는 그대로다 (D6).

### 들어가는 것

| 기능 | 상태 |
|---|---|
| 카톡 파싱 · 날짜 분할 | 동작함 |
| 미리보기 승인 게이트 | 동작함 |
| **그 날 대화 전체 번역** | 동작함 (D18) |
| 스와이프 채점 · FSRS | 동작함 |
| 음성으로 말하고 채점 | 동작함, 기기 지원 시 |
| 진도 저장 (기기 내) | 동작함 |
| 번역 프록시 서버 | 코드·테스트 완료, **미배포** — 배포는 계정이 필요하다 |

### 빼는 것 — 그리고 이유

| 뺀 기능 | 이유 |
|---|---|
| **직무별 표현집 (200장)** | 범위를 두 기능으로 좁힘 (D20). 코드와 카드는 남기고 화면에서만 내린다 |
| AI 롤플레이 | 구현 난이도 (D10). 재료는 v1이 만들어두므로 다음 단계는 화면을 붙이는 일 |
| 사용자 기여 덱 | 백엔드 필요 (D17) |
| 기기 간 동기화 | 계정 필요 |
| 알림·리마인더 | 습관이 붙는지 먼저 보고 나서 |

### 직무 덱을 뺀 대가

정직하게 적어둔다. 직무 덱은 `built: true`로 **영어가 카드에 같이 실려 있어**
번역 없이 돌아가는 유일한 경로였다. 이걸 내리면:

- **번역 서버가 선택이 아니라 진입 조건이 된다.** 서버 없이는 앱이 아무것도 못 한다
- **남에게 보여줄 수단이 당분간 없다.** 테스터는 자기 카톡을 내보내야 하고,
  번역까지 되려면 서버가 있어야 한다
- **첫 실행 온보딩을 다시 설계해야 한다.** 지금 화면은 직무를 고르게 하는데,
  고를 직무가 v1에 없다

### 번역 서버

클라이언트 요청을 받아 서버가 보관한 키로 Anthropic에 중계하는 프록시 하나.
로직은 작지만 **책임이 따라온다** — 비용 상한, 남용 방지, 요청 로그를 남기지
않는 것(대화 문장이 지나간다).

비용은 전체 번역으로 바뀌어도 걱정거리가 아니다. 출력 토큰은 2~3배가 되지만
입력은 오히려 줄어든다 — 지금은 한 메시지가 뒤따르는 발화들의 맥락으로 여러 번
전송되는데, 하루치를 통째로 보내면 한 번씩만 들어간다 (D18). 세션당 ~$0.01에서
~$0.02 수준.

### v1 출시 전 반드시 해야 하는 일

**Android 먼저, iOS는 보류** (D21). 우선순위 순, **0번이 1번보다 먼저다.**

0. **본인이 2주 써보기** — 아무도 이 앱을 실제로 써본 적이 없다. `decisions.md`의
   "미해결" 표에 있는 값들(스와이프 140px, 음성 채점 70%, 세션 분량)은 전부 내가
   임의로 정한 것이다. 아티팩트 링크로 지금 바로 되고, 키도 서버도 필요 없다
1. **번역 서버 배포** — 코드·테스트 20개(단위 12 + 통합 8) 끝났고, 앱과 실제로
   붙여서 브라우저로 확인까지 했다. 남은 건 Cloudflare 계정에 올리고 `PROXY_URL`을
   채우는 일뿐이다 (`server/README.md` — 터미널 없이 웹 화면에서 끝난다).
   **테스터가 쓰려면 이게 먼저다**
2. ~~**레포 공개 + Pages**~~ — 끝남 (D22). 앱·소개·처리방침 전부 공개 주소로 뜬다
3. **Play 개발자 계정** — $25, 1회
4. **테스터 12명 × 14일** — 비공개 테스트 트랙에서만 인정된다. 내부 테스트(100명,
   즉시)는 배포는 되지만 이 요건에 쳐주지 않는다. **가장 오래 걸리는 항목이고,
   돈이 아니라 사람과 시간이 든다**
5. **스토어 제출** — 문구·스크린샷·처리방침 완료 (`store/`)

iOS는 Android 다음이다. **Mac이 없어서가 아니다** — 레포가 공개라 macOS 러너가
무료이고, App Store Connect API 키로 CI에서 서명과 TestFlight 업로드까지 된다.
필요한 건 Apple $99/년과 서명 설정이며, Android($25, 설정 간단)를 먼저 끝내고
붙이는 게 순서상 낫다는 판단이다 (D21).

## 5. 성공을 어떻게 아는가

v1에서 답을 얻고 싶은 질문은 **"사람들이 다시 오는가"** 하나다.

| 지표 | 최소선 | 어떻게 재나 |
|---|---|---|
| D1 재방문 | 40% | 스토어 콘솔 |
| D7 재방문 | 20% | 스토어 콘솔 |
| 첫 세션 완주율 | 60% | 덱을 끝까지 넘긴 비율 |
| 세션당 카드 수 | 15장 이상 | — |

**측정하지 않는 것**: 학습 효과. "실제로 입에서 나오는가"(D4)는 v1에서 잴 방법이
없다. 재방문이 대리 지표다.

⚠️ v1에는 분석 도구가 전혀 없다. 스토어 콘솔 기본 지표 외에는 아무것도 안 보인다.
세션 지표까지 보려면 분석 SDK를 붙여야 하고, 그러면 개인정보 처리방침이 달라진다.

## 7. 비범위 — 하지 않기로 한 것

이건 "나중에"가 아니라 **하지 않는다**는 뜻이다.

- **카톡 대화 자동 수집** — 공식 API로 불가능하고, 알림 접근·접근성 서비스·로컬 DB는
  전부 스토어 정책 위반 또는 동의 없는 제3자 정보 수집이다 (decisions.md 배제 목록)
- **대화 로그 공유** — 공유 단위는 카드다. 원문은 절대 서버로 가지 않는다 (D16)
- **일반 영어 회화** — 직장 맥락을 벗어나면 이 앱이 이길 이유가 없다
