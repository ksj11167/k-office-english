개인정보 처리방침

K-직장인 영어 · 최종 수정 2026-09-16

이 앱은 카카오톡 대화 내보내기 파일을 영어로 옮기고, 그 중 사용자가 한 말을 말하기 연습 카드로 만듭니다. 다루는 내용이 사적인 대화이므로, 무엇을 보내고 무엇을 안 보내는지 구체적으로 적습니다.

한 줄 요약

계정이 없고, 서버에 대화를 저장하지 않으며, 광고와 분석 도구를 넣지 않았습니다. 대화는 기기 안에서 읽고, 영어로 옮기는 그 순간에만 번역 제공자에게 전송됩니다.

수집하지 않는 것

  • 이름, 이메일, 전화번호, 생년월일 등 어떤 개인 식별 정보도 받지 않습니다. 회원가입이 없습니다
  • 연락처, 사진, 위치, 통화 기록에 접근하지 않습니다
  • 광고 식별자를 읽지 않고, 광고·분석 SDK를 넣지 않았습니다
  • 대화 내용을 서버에 저장하지 않습니다

기기 안에만 남는 것

무엇어디언제 사라지나
불러온 대화와 영어 번역기기 브라우저 저장소앱에서 «모두 지우기» 또는 앱 삭제
카드별 복습 일정기기 브라우저 저장소위와 같음
직접 넣은 API 키(선택)기기 브라우저 저장소위와 같음

이 데이터는 기기를 떠나지 않습니다. 기기 간 동기화 기능이 없고, 따라서 사용자의 카드를 다른 곳에서 볼 방법이 없습니다 — 개발자도 마찬가지입니다.

번역할 때 전송되는 것

영어로 옮기려면 그 날 대화 문장이 언어 모델에 전달되어야 합니다. 이때 전송되는 것은 선택한 날짜의 대화 텍스트와 발화자 표시 이름뿐입니다. 전화번호, 프로필, 대화방 식별자, 첨부 파일은 전송되지 않습니다. 사진·이모티콘 등은 자리표시자로만 남고 번역 대상이 아닙니다.

전송 경로는 셋 중 하나이며, 앱이 어디서 실행되는지에 따라 정해집니다.

경로어디로보관
앱 기본(번역 서버)운영자의 프록시 서버 → Anthropic프록시는 대화를 저장하지 않습니다
본인 API 키 입력 시기기 → Anthropic 직접운영자를 거치지 않습니다
Claude 아티팩트로 열었을 때보는 사람 본인의 Claude운영자를 거치지 않습니다

번역 서버가 남기는 기록

프록시 서버는 대화 내용을 기록하지 않습니다. 프롬프트도, 응답도, 오류가 났을 때도 남기지 않습니다. 남기는 것은 남용을 막기 위한 하루치 요청 횟수 하나이며, 그 횟수는 IP 주소가 아니라 서버 비밀값을 섞어 해시한 값에 대해 셉니다. 이 값은 되돌려 IP를 알아낼 수 없고 48시간 뒤 자동 삭제됩니다.

Anthropic으로 전달되는 부분

번역은 Anthropic의 Claude 모델이 수행합니다. 전달된 내용의 처리는 Anthropic이 API 이용자에게 적용하는 약관과 개인정보 방침을 따릅니다 (anthropic.com/legal/privacy). 이 부분은 운영자가 통제하지 않으며, 운영자가 Anthropic 측의 데이터 처리에 대해 별도로 설정하는 값은 없습니다.

음성 인식

말하기 채점은 기기의 음성 인식을 사용합니다. 처리 위치는 실행 환경에 따라 다르며, 이 차이는 앱이 통제할 수 없습니다.

  • iOS·Android 앱에서는 기기 안에서 처리됩니다. 음성이 기기를 떠나지 않습니다
  • 웹 브라우저에서는 브라우저가 정합니다. 특히 Chrome은 음성을 구글 서버로 전송합니다

녹음 파일은 어떤 경우에도 앱이 저장하지 않으며, 인식된 문자열은 채점 직후 버려집니다.

대화 상대방에 대하여

대화에는 동의한 적 없는 상대방의 발화가 포함됩니다. 이 점을 고려해 앱은 다음을 지킵니다.

  • 대화 원문은 다른 사용자에게 공유되지 않습니다. 공유 기능 자체가 없습니다
  • 대화를 서버에 저장하지 않으므로, 유출될 저장본이 존재하지 않습니다
  • 번역 목적 외로 사용하지 않습니다

다만 대화를 불러오는 행위 자체는 사용자의 선택입니다. 직장 단체 대화방 등 민감한 내용이 포함된 대화를 불러올지는 사용자가 판단해 주시기 바랍니다.

만 14세 미만

이 앱은 직장인을 대상으로 하며 만 14세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 수집하지 않습니다.

권리와 삭제

모든 데이터가 기기에만 있으므로, 설정 화면의 «대화와 진도 모두 지우기» 또는 앱 삭제로 즉시 전부 삭제됩니다. 서버에 보관된 사용자 데이터가 없어 별도의 삭제 요청 절차가 필요하지 않습니다.
